## 왜 필요한가

스팸인가 아닌가, 고양이인가 아닌가처럼 답이 0 또는 1인 문제에 linear regression을 그대로 쓰면 예측값이 −3이나 7처럼 확률로 해석할 수 없는 값이 나온다. 출력을 0~1 사이로 눌러주는 함수(sigmoid)와, 확률 출력에 맞는 loss(binary cross-entropy)가 필요하다. MSE를 그대로 쓰면 모델이 **크게 틀렸을 때 오히려 학습이 거의 멈추는** 문제가 생긴다. 이 레슨에서 그 이유를 숫자로 보고, 04번 레슨의 softmax와 cross-entropy로 일반화한다.

## 직관: 점수를 확률로 바꾸는 밸브

linear 부분 $z = wx + b$는 "고양이 같은 정도"를 나타내는 **점수**다. 범위가 −∞~∞라서 그대로는 확률이 아니다. sigmoid는 이 점수를 0~1로 부드럽게 눌러주는 밸브다.

```text
 σ(z)
 1.0 |                      ___________
     |                  _--
 0.5 |- - - - - - - - -●- - - - - - - -   z = 0에서 정확히 0.5
     |            _--
 0.0 |___________-
     └────────────┬─────────────────── z
                  0
   z가 아주 작으면 0에 붙고, 아주 크면 1에 붙는다 (saturation)
```

- $z = 0$ 근처에서는 점수가 조금만 바뀌어도 확률이 크게 바뀐다.
- $|z|$가 크면 곡선이 평평해서 점수를 바꿔도 확률이 거의 안 변한다. 이 평평한 구간이 MSE 문제의 원인이다.

## 정식 설명

### 용어

**Logistic regression (로지스틱 회귀)**: 입력의 선형 점수를 sigmoid에 넣어 클래스 1일 확률을 출력하는 분류 모델.
*A classification model that outputs the probability of class 1 as the sigmoid of a linear score.*

**Sigmoid (시그모이드, logistic function)**: $\sigma(z) = 1 / (1 + e^{-z})$. 실수 전체를 (0, 1)로 보낸다.

**Logit (로짓)**: 확률의 log-odds $\log \frac{p}{1-p}$. sigmoid의 역함수이고, logistic regression에서는 linear 점수 $z$ 자체다.

**Decision boundary (결정 경계)**: 모델이 0.5 확률을 내는 입력의 집합. 클래스를 가르는 경계.

**Binary cross-entropy, BCE (이진 교차 엔트로피)**: 확률 예측 $p$와 정답 $y \in \{0, 1\}$에 대한 loss $-[y \log p + (1-y)\log(1-p)]$.
*The negative log-likelihood of a Bernoulli prediction.*

### 모델

$$
z = \mathbf{w}^\top \mathbf{x} + b, \qquad p = \sigma(z) = \frac{1}{1 + e^{-z}} = P(y = 1 \mid \mathbf{x})
$$

**sigmoid의 성질** (전부 유도할 수 있다)

1. $\sigma(-z) = 1 - \sigma(z)$. 분자 분모에 $e^z$를 곱하면 $\frac{e^z}{e^z + 1} = 1 - \frac{1}{1 + e^z}$.
2. $\sigma'(z) = \sigma(z)(1 - \sigma(z))$.

$$
\sigma'(z) = \frac{e^{-z}}{(1 + e^{-z})^2} = \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}} = \sigma(z)\,(1 - \sigma(z))
$$

최댓값은 $z = 0$에서 $0.25$이고, $|z|$가 커지면 0으로 간다.

3. 역함수: $p = \sigma(z) \Leftrightarrow z = \log\frac{p}{1-p}$ (logit).

**Decision boundary**: $p \ge 0.5 \Leftrightarrow z \ge 0$이므로 경계는 $\mathbf{w}^\top \mathbf{x} + b = 0$, 입력 공간의 **직선(평면)**이다. logistic regression은 선형 분류기다.

### Loss 유도: maximum likelihood

모델이 각 데이터의 정답이 나올 확률을 $p_i$ (정답이 1일 때) 또는 $1 - p_i$ (정답이 0일 때)로 예측한다. 한 식으로 쓰면 $p_i^{y_i}(1-p_i)^{1-y_i}$다. 데이터가 독립이면 전체 likelihood는 곱이고, log를 씌워 부호를 뒤집고 평균을 내면

$$
L = -\frac{1}{N}\sum_{i=1}^{N} \Big[\, y_i \log p_i + (1 - y_i)\log(1 - p_i) \,\Big]
$$

이게 BCE다. 01번 레슨에서 MSE가 "Gaussian 노이즈의 likelihood"였던 것처럼 BCE는 "Bernoulli의 likelihood"다.

### Gradient 유도

데이터 하나에 대해 $\ell = -[y\log p + (1-y)\log(1-p)]$, $p = \sigma(z)$.

$$
\frac{\partial \ell}{\partial p} = -\frac{y}{p} + \frac{1-y}{1-p} = \frac{p - y}{p(1-p)}
$$

$$
\frac{\partial \ell}{\partial z} = \frac{\partial \ell}{\partial p}\cdot\sigma'(z) = \frac{p - y}{p(1-p)} \cdot p(1-p) = \boxed{p - y}
$$

sigmoid의 미분 $p(1-p)$가 **정확히 상쇄**된다. 그래서

$$
\frac{\partial L}{\partial \mathbf{w}} = \frac{1}{N}\sum_i (p_i - y_i)\,\mathbf{x}_i, \qquad \frac{\partial L}{\partial b} = \frac{1}{N}\sum_i (p_i - y_i)
$$

linear regression의 gradient $\frac{2}{N}\sum r_i \mathbf{x}_i$와 모양이 같다. 잔차 자리에 "예측 확률 − 정답"이 들어간다.

### MSE를 쓰면 생기는 문제

loss를 $(p - y)^2$로 두면

$$
\frac{\partial}{\partial z}(p - y)^2 = 2(p - y)\cdot p(1-p)
$$

이번에는 $p(1-p)$가 **남는다.** 모델이 확신을 갖고 틀린 경우($y = 1$인데 $z$가 아주 작아서 $p \approx 0$), $p(1-p) \approx 0$이라 gradient가 거의 0이 된다. 가장 많이 고쳐야 할 때 가장 적게 고친다. BCE는 이때 gradient가 $p - y \approx -1$로 크게 유지된다.

## Worked example

feature 하나, $w = 1.5$, $b = -3$. 데이터 3개: $(x, y) = (1, 0), (3, 1), (2.5, 0)$.

**Step 1. 점수, 확률, loss**

| $x$ | $y$ | $z = 1.5x - 3$ | $p = \sigma(z)$ | 데이터 loss |
|---|---|---|---|---|
| 1 | 0 | −1.5 | 0.1824 | $-\log(1 - 0.1824) = 0.2014$ |
| 3 | 1 | 1.5 | 0.8176 | $-\log(0.8176) = 0.2014$ |
| 2.5 | 0 | 0.75 | 0.6792 | $-\log(1 - 0.6792) = 1.1369$ |

평균 BCE $= (0.2014 + 0.2014 + 1.1369) / 3 \approx 0.513$. 세 번째 데이터가 0인데 68%로 1이라고 예측해서 loss의 대부분을 차지한다.

첫 두 데이터의 loss가 같은 건 $\sigma(-1.5) = 1 - \sigma(1.5)$이기 때문이다.

**Step 2. Gradient**

$p - y = 0.1824, -0.1824, 0.6792$

$$
\frac{\partial L}{\partial w} = \frac{0.1824 \times 1 - 0.1824 \times 3 + 0.6792 \times 2.5}{3} \approx 0.444, \qquad \frac{\partial L}{\partial b} = \frac{0.6792}{3} \approx 0.226
$$

둘 다 양수 → $w$와 $b$를 줄인다. 경계 $x = -b/w = 2$를 오른쪽으로 밀어서 $x = 2.5$를 0 쪽으로 보내려는 움직임이다.

**Step 3. MSE vs BCE gradient** ($y = 1$인데 $z = -4$, 즉 $p = 0.018$로 확신하고 틀린 경우)

| loss | $\partial \ell / \partial z$ |
|---|---|
| BCE | $p - y = -0.982$ |
| MSE | $2(p - y)\,p(1-p) = 2(-0.982)(0.0177) = -0.0347$ |

MSE의 gradient가 **28배 작다.** $z = -6$이면 200배 작다.

## 코드

```python
import numpy as np

def sigmoid(z):
    # 큰 음수에서 exp(-z) overflow를 피하는 안정적인 버전
    out = np.empty_like(z, dtype=float)
    pos = z >= 0
    out[pos] = 1 / (1 + np.exp(-z[pos]))
    ez = np.exp(z[~pos])
    out[~pos] = ez / (1 + ez)
    return out

def bce(p, y, eps=1e-12):
    p = np.clip(p, eps, 1 - eps)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

# worked example
w, b = 1.5, -3.0
x = np.array([1, 3, 2.5]); y = np.array([0, 1, 0.])
p = sigmoid(w * x + b)
print("p =", p.round(4), " BCE =", round(bce(p, y), 4))
print("dw =", round(np.mean((p - y) * x), 4), " db =", round(np.mean(p - y), 4))

# BCE vs MSE로 학습: 나쁜 초기값(확신하고 틀림)에서 시작
rng = np.random.default_rng(0)
N = 200
xs = np.r_[rng.normal(-2, 1, N // 2), rng.normal(2, 1, N // 2)]
ys = np.r_[np.zeros(N // 2), np.ones(N // 2)]

for name in ["BCE", "MSE"]:
    w, b, lr = -3.0, 0.0, 0.5            # 반대 방향으로 확신하는 초기값
    for step in range(301):
        p = sigmoid(w * xs + b)
        g = (p - ys) if name == "BCE" else 2 * (p - ys) * p * (1 - p)
        w -= lr * np.mean(g * xs)
        b -= lr * np.mean(g)
        if step in (0, 50, 300):
            acc = np.mean((p >= 0.5) == ys)
            print(f"{name} step {step:3d}  w={w:6.3f}  accuracy={acc:.2f}")
```

볼 포인트: 같은 learning rate, 같은 나쁜 초기값에서 50 걸음 뒤 BCE는 정확도 0.98, MSE는 아직 0.03이다. MSE는 sigmoid가 포화된 구간에서 gradient가 작아 300 걸음 가까이 지나서야 빠져나온다.

## 흔한 오해

<Aside type="caution" title="Logistic regression은 이름에 regression이 있으니 회귀 모델이다?">
이름은 역사적인 이유다. 출력이 확률이고 그 확률로 클래스를 고르는 **분류** 모델이다. regression이라는 이름은 log-odds(logit)를 입력의 선형 함수로 회귀한다는 데서 왔다.
</Aside>

<Aside type="caution" title="출력 확률 0.5가 넘으면 모델이 정답을 안다?">
0.5 기준은 두 클래스의 오류 비용이 같을 때의 선택일 뿐이다. 암 진단처럼 놓치는 비용이 크면 기준을 낮춘다. 그리고 출력 확률이 실제 확률과 맞는지(calibration)는 따로 확인해야 한다.
</Aside>

<Aside type="caution" title="분류에도 MSE를 써도 결과는 비슷하다?">
sigmoid와 같이 쓰면 확신하고 틀린 데이터에서 gradient가 사라진다(위 Worked example의 28배). loss를 고를 때는 출력 함수의 미분까지 같이 봐야 한다.
</Aside>

## Efficient ML 연결

**Sigmoid는 activation으로도 쓰인다.** Llama 계열 LLM의 FFN은 SwiGLU를 쓰는데, 그 안의 SiLU(Swish)가 $x \cdot \sigma(x)$다. 즉 sigmoid가 모든 FFN layer에 들어 있다.

**MCU에서는 exp가 비싸다.** sigmoid를 그대로 계산하려면 지수 함수가 필요한데, FPU가 없거나 약한 MCU에서는 이게 MAC보다 훨씬 비싸다. MobileNetV3는 sigmoid를 **hard-sigmoid** $\text{ReLU6}(x + 3)/6$로 바꿨다. 곱셈 하나, 덧셈 하나, clamp 하나라서 INT8로도 쉽게 계산된다. 최대 오차는 약 0.07이고 정확도 손실은 거의 없다. 6.5940의 efficient model design에서 이런 근사가 나온다. 다른 방법은 lookup table(LUT)로 INT8 입력 256개에 대한 출력을 미리 저장하는 것이다.

**Calibration과 edge 모델.** quantization이나 pruning 후에는 정확도가 비슷해도 출력 확률이 과신(overconfident)하는 쪽으로 틀어질 수 있다. 이런 모델의 신뢰도를 보정하는 연구가 logistic regression(Platt scaling) 위에 서 있다.

## 서술형

### 문제. logistic regression 한 걸음과 hard-sigmoid 근사

(a) 데이터 $(x, y) = (2, 1), (-1, 1)$, 초기값 $w = 0.5, b = 0$, learning rate 0.5다. 각 데이터의 $p$, 평균 BCE, $\partial L/\partial w$, $\partial L/\partial b$를 구하고 한 걸음 업데이트하라.

(b) 업데이트 후 $w$가 오히려 **줄었다.** 왜인가? 두 데이터를 동시에 맞추려면 $w, b$가 어떻게 되어야 하나?

(c) hard-sigmoid $h(z) = \text{clip}(z + 3, 0, 6)/6$을 $z = -3, 0, 1, 2$에서 계산해서 sigmoid와 비교하라. INT8 MCU에서 이 근사가 유리한 이유를 연산 종류로 설명하라.

<details>
<summary>풀이 보기</summary>

**(a)** $z = 1, -0.5$ → $p = \sigma(1) \approx 0.7311$, $\sigma(-0.5) \approx 0.3775$.

$$
L = -\frac{\log 0.7311 + \log 0.3775}{2} = \frac{0.3133 + 0.9741}{2} \approx 0.644
$$

$p - y = -0.2689, -0.6225$.

$$
\frac{\partial L}{\partial w} = \frac{-0.2689 \times 2 + (-0.6225)(-1)}{2} \approx 0.0423, \qquad \frac{\partial L}{\partial b} = \frac{-0.2689 - 0.6225}{2} \approx -0.4457
$$

$$
w = 0.5 - 0.5 \times 0.0423 \approx 0.479, \qquad b = 0 - 0.5 \times (-0.4457) \approx 0.223
$$

**(b)** $x = -1$인 데이터도 정답이 1인데, 그 데이터는 $w$가 클수록 $z = -w + b$가 작아져서 손해다. 이 데이터의 gradient 기여 $(p - y)x = (-0.6225)(-1) = +0.62$가 첫 데이터의 $-0.54$보다 커서 $w$를 줄이는 쪽이 이겼다. 두 데이터 모두 클래스 1이므로 정답은 "$x$와 상관없이 1", 즉 $w \to 0$, $b \to$ 큰 양수다. 실제로 $b$가 크게 올랐다.

**(c)**

| $z$ | $\sigma(z)$ | $h(z)$ | 차이 |
|---|---|---|---|
| −3 | 0.047 | 0 | 0.047 |
| 0 | 0.5 | 0.5 | 0 |
| 1 | 0.731 | 0.667 | 0.064 |
| 2 | 0.881 | 0.833 | 0.047 |

최대 오차는 약 0.07이다($z \approx \pm 1.3$ 근처). sigmoid는 지수 함수와 나눗셈이 필요하지만 $h(z)$는 덧셈, 상수 곱(INT8에서는 shift와 정수 곱으로 근사), clamp뿐이라 SIMD 정수 명령어 몇 개로 끝난다.

</details>
