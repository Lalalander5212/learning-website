## 왜 필요한가

01~16번 레슨의 내용은 실제로는 한꺼번에 쓰인다. 모델 하나를 학습하려면 loss를 정하고(01~04), gradient를 구하고(09~12), optimizer와 learning rate를 고르고(05~08), overfitting을 막고 validation으로 설정을 골라야 한다(13~16). 이 레슨은 계산 문제 위주로 트랙 전체를 점검한다. 계산기와 종이를 준비하자.

<Aside type="tip" title="푸는 순서">
객관식은 먼저 손으로 계산하고 보기를 고르자. 서술형은 풀이를 펼치기 전에 끝까지 직접 풀어보는 게 핵심이다. 틀린 문제는 문제 앞에 적힌 레슨 번호로 돌아가 복습하자.
</Aside>

## 서술형

### 문제 1. 학습 한 step 손으로 따라가기

관련 레슨: 09, 10, 11, 05, 08, 12번 레슨

hidden unit 1개짜리 네트워크: $z = w_1 x + b_1$, $h = \text{ReLU}(z)$, $\hat{y} = w_2 h + b_2$, loss $L = \frac{1}{2}(\hat{y} - y)^2$.

$x = 1.5$, $y = 1$, 초기값 $w_1 = 0.4$, $b_1 = -0.1$, $w_2 = -0.5$, $b_2 = 0.2$.

(a) forward로 $z, h, \hat{y}, L$을 구하라.

(b) backward로 네 파라미터의 gradient를 구하라.

(c) SGD($\eta = 0.1$)로 한 step 업데이트하고 새 loss를 구하라.

(d) 같은 초기값에서 Adam($\eta = 0.1$, 기본 $\beta$, $\epsilon$ 무시)으로 첫 step을 하면 각 파라미터가 얼마나 움직이나? 새 loss는?

(e) $w_1$에 대해 central difference($h = 10^{-5}$) gradient check를 하면 (b)의 값과 얼마나 맞을까? 이 함수에서 central difference가 특히 정확한 이유는?

<details>
<summary>풀이 보기</summary>

**(a)** $z = 0.4 \times 1.5 - 0.1 = 0.5$, $h = 0.5$, $\hat{y} = -0.5 \times 0.5 + 0.2 = -0.05$, $L = \frac{1}{2}(-1.05)^2 = 0.55125$.

**(b)** $\bar{\hat{y}} = \hat{y} - y = -1.05$.

- $\bar{w}_2 = \bar{\hat{y}} \cdot h = -0.525$, $\bar{b}_2 = -1.05$
- $\bar{h} = \bar{\hat{y}} \cdot w_2 = 0.525$
- ReLU: $z = 0.5 > 0$이므로 통과, $\bar{z} = 0.525$
- $\bar{w}_1 = \bar{z} \cdot x = 0.7875$, $\bar{b}_1 = 0.525$

**(c)** $w_1 = 0.4 - 0.07875 = 0.32125$, $b_1 = -0.1 - 0.0525 = -0.1525$, $w_2 = -0.5 + 0.0525 = -0.4475$, $b_2 = 0.2 + 0.105 = 0.305$.

새 forward: $z = 0.32125 \times 1.5 - 0.1525 = 0.329375$, $\hat{y} = -0.4475 \times 0.329375 + 0.305 = 0.1576$, $L = \frac{1}{2}(0.8424)^2 = 0.3548$. 0.551에서 0.355로 줄었다.

**(d)** Adam 첫 step은 bias correction 후 $\hat{m} = g$, $\sqrt{\hat{s}} = \lvert g \rvert$라서 각 파라미터가 $\eta \cdot \text{sign}(g)$의 반대 방향으로 **정확히 0.1씩** 움직인다(08번 레슨).

$w_1 = 0.3$, $b_1 = -0.2$, $w_2 = -0.4$, $b_2 = 0.3$. 새 forward: $z = 0.45 - 0.2 = 0.25$, $\hat{y} = -0.4 \times 0.25 + 0.3 = 0.2$, $L = \frac{1}{2}(0.8)^2 = 0.32$.

이 step에서는 Adam이 더 많이 줄였지만 일반적인 결론은 아니다. gradient가 작았던 $b_1$($0.525$)도 gradient가 큰 $b_2$($1.05$)와 똑같이 움직였다는 점이 Adam의 특징이다.

**(e)** central difference 값은 약 $0.7875$로 상대 오차 $10^{-11}$ 수준까지 맞는다. $z = 0.5$가 ReLU의 꺾인 점에서 멀어서 $w_1 \pm 10^{-5}$에서도 같은 선형 구간이고, 그 구간에서 $\hat{y}$는 $w_1$에 대해 1차, $L$은 2차 함수다. central difference의 truncation 오차는 $\frac{h^2}{6}f'''$인데 2차 함수는 $f''' = 0$이라 truncation 오차가 0이다. 남는 것은 round-off뿐이다(12번 레슨).

</details>

### 문제 2. Ridge 강도를 bias-variance로 고르기

관련 레슨: 13, 15, 16번 레슨

feature 하나짜리 linear regression $y = w^* x + \varepsilon$에서 $S = \frac{1}{N}\sum x_i^2 = s$, noise 분산 $\sigma^2$이다. regularization 없는 해 $\hat{w}$는 평균 $w^*$, 분산 $\frac{\sigma^2}{Ns}$이다. ridge 해는 $w_\lambda = \frac{s}{s + \lambda}\hat{w}$다.

(a) $w_\lambda$의 bias²와 variance를 $c = \frac{s}{s + \lambda}$로 쓰고, MSE $\mathbb{E}[(w_\lambda - w^*)^2]$를 최소화하는 $c^*$와 $\lambda^*$를 구하라.

(b) $w^* = 1$, $\sigma^2 = 1$, $N = 20$, $s = 0.5$일 때 $\lambda^*$, $c^*$, 최소 MSE를 구하고, $\lambda = 0$의 MSE와 비교하라.

(c) 이 $\lambda^*$와 비슷한 효과를 early stopping으로 얻으려면 learning rate 0.1에서 대략 몇 step에 멈춰야 하나?

(d) 실제로는 $w^*$를 모른다. $\lambda$를 고르는 절차를 쓰고, 고른 뒤 최종 성능을 무엇으로 보고하는지 설명하라.

<details>
<summary>풀이 보기</summary>

**(a)** $\mathbb{E}[w_\lambda] = cw^*$이므로 bias² $= (1 - c)^2 w^{*2}$, variance $= c^2\frac{\sigma^2}{Ns}$.

$$
\text{MSE}(c) = (1 - c)^2 w^{*2} + c^2 v, \quad v = \frac{\sigma^2}{Ns}
$$

13번 레슨 서술형과 같은 꼴이므로 $c^* = \frac{w^{*2}}{w^{*2} + v}$. $c = \frac{s}{s + \lambda}$에서 $\lambda = s\frac{1 - c}{c}$이고 $\frac{1 - c^*}{c^*} = \frac{v}{w^{*2}}$이므로

$$
\lambda^* = s \cdot \frac{v}{w^{*2}} = \frac{\sigma^2}{N w^{*2}}
$$

15번 레슨의 MAP 해석($\lambda = \sigma^2 / (N\tau^2)$)과 같은 모양이다. prior의 분산 $\tau^2$ 자리에 $w^{*2}$가 들어갔다.

**(b)** $v = 1/(20 \times 0.5) = 0.1$. $\lambda^* = 1/20 = 0.05$, $c^* = 1/1.1 = 0.909$. 최소 MSE $= \frac{w^{*2} v}{w^{*2} + v} = 0.1/1.1 = 0.0909$. $\lambda = 0$이면 MSE $= v = 0.1$이므로 약 9% 줄었다. 검산: bias² $= 0.0909^2 = 0.00826$, variance $= 0.826 \times 0.1 = 0.0826$, 합 0.0909.

**(c)** $\lambda \approx \frac{1}{\eta t}$이므로 $t \approx \frac{1}{0.1 \times 0.05} = 200$ step. (이 방향의 정확한 early stopping 배율은 $1 - (1 - 0.1 \times 0.5)^{200} \approx 1.0$이라, 곡률 0.5는 "작은 곡률" 근사가 맞지 않는다. 근사가 맞는 건 $\eta s t$가 작은 방향이다. 16번 레슨 예제 3처럼 곡률이 큰 방향에서는 early stopping이 ridge보다 덜 줄인다.)

**(d)** 데이터를 train / validation / test로 나눈다. $\lambda$ 후보(예: $10^{-4}$부터 10배씩)마다 train으로 학습하고 validation MSE를 잰다. 가장 낮은 $\lambda$를 고른다(데이터가 적으면 k-fold CV). 고른 $\lambda$로 train(+ validation)에 다시 학습하고, **선택에 한 번도 쓰지 않은 test set**에서 한 번만 평가해 보고한다. validation 점수는 selection bias 때문에 낙관적이다(14번 레슨).

</details>

### 문제 3. 1.3B 모델 fine-tuning 계획

관련 레슨: 06, 08, 11, 15번 레슨

1.3B 파라미터 모델을 GPU 한 장(메모리 24 GB, 실효 40 TFLOP/s)에서 1억($10^8$) token으로 fine-tuning한다.

(a) full fine-tuning을 mixed precision Adam(16 B/param)으로 하면 weight + gradient + optimizer state 메모리는? 24 GB에 들어가나? activation까지 생각하면?

(b) (i) 8-bit Adam, (ii) LoRA(파라미터의 0.5%만 학습, 나머지는 FP16 고정)의 메모리를 같은 기준으로 구하라. LoRA 파라미터는 16 B/param으로 센다.

(c) full fine-tuning의 학습 시간을 token당 $6N$ FLOPs로 어림하라. LoRA는 frozen weight의 $\partial W$를 건너뛴다. adapter 연산을 무시하면 token당 FLOPs와 시간은?

(d) 메모리 때문에 micro-batch는 4로 하고 global batch 64로 학습하려 한다. 몇 번 accumulation하나? 나중에 GPU를 늘려 global batch를 256으로 키우면 learning rate는 어떻게 바꾸는 게 출발점인가?

<details>
<summary>풀이 보기</summary>

**(a)** $1.3 \times 10^9 \times 16 = 20.8$ GB. 24 GB에 숫자상으로는 들어가지만 남는 3.2 GB로 activation(batch × sequence × hidden × layer에 비례)과 CUDA 작업 공간을 감당하기는 거의 불가능하다. 사실상 안 된다.

**(b)** (i) $2 + 2 + 4 + 1 + 1 = 10$ B/param → $13$ GB. 11 GB가 남아 activation에 쓸 수 있다.

(ii) 고정 weight $1.3 \times 10^9 \times 2 = 2.6$ GB, 학습 파라미터 $6.5 \times 10^6 \times 16 = 0.104$ GB, 합 약 $2.7$ GB. 나머지 대부분을 activation에 쓸 수 있다.

**(c)** full: token당 $6 \times 1.3 \times 10^9 = 7.8$ GFLOPs, 전체 $7.8 \times 10^{17}$ FLOPs. $7.8 \times 10^{17} / (40 \times 10^{12}) = 19{,}500$ s ≈ **5.4시간**.

LoRA: forward $2N$ + backward의 $\partial X = GW$ 부분 $2N$ = $4N$ (11번 레슨). token당 5.2 GFLOPs, 전체 $5.2 \times 10^{17}$ FLOPs → 13,000 s ≈ **3.6시간**. 계산은 1/3만 줄지만 메모리는 약 8배 줄어든다. LoRA의 주된 이득은 메모리다.

**(d)** $64 / 4 = 16$번 accumulation. micro-batch gradient의 평균이 global batch gradient와 같다(06번 레슨). global batch를 4배로 키우면 linear scaling rule로 learning rate도 4배가 출발점이다. noise floor가 $\eta / B$에 비례하기 때문이다. Adam에서는 4배가 너무 커서 $\sqrt{4} = 2$배로 시작하기도 하고, 어느 쪽이든 warmup을 같이 쓰고 validation loss로 확인한다.

</details>
