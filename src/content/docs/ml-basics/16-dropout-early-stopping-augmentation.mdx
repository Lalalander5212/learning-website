## 왜 필요한가

15번 레슨의 L1, L2는 loss에 벌점 항을 직접 더했다. 신경망에서는 그 외에도 **학습 과정을 바꿔서** variance를 줄이는 방법을 많이 쓴다. 학습 중에 neuron을 무작위로 끄거나(dropout), validation error가 오르기 시작하면 멈추거나(early stopping), 입력을 조금씩 바꿔서 데이터를 불리거나(data augmentation). 이 셋은 따로 노는 요령처럼 보이지만, 간단한 모델에서 계산해 보면 전부 L2 regularization과 비슷한 효과를 낸다. 이 레슨에서 그 연결을 식으로 보인다.

## 직관

```text
 Dropout          매 step 일부 neuron을 랜덤으로 끔
                  → 특정 neuron에 기대는 "공모(co-adaptation)"가 어려워짐
                  → 매번 다른 작은 네트워크를 학습하는 것 = 많은 모델의 앙상블

 Early stopping   GD는 곡률 큰(데이터가 잘 정하는) 방향부터 맞추고
                  곡률 작은(noise가 큰) 방향은 나중에 맞춤
                  → 일찍 멈추면 noise 방향을 덜 학습한 상태

 Augmentation     고양이 사진을 뒤집어도, 조금 잘라도 고양이
                  → "이런 변화에는 답이 안 바뀐다"는 지식을 데이터로 주입
```

## 정식 설명

### 용어

**Dropout (드롭아웃)**: 학습 중 각 activation을 확률 $p$로 0으로 만드는 것. $p$는 drop 확률.
*Randomly zeroing each activation with probability p during training.*

**Inverted dropout**: 남긴 값을 $1/(1 - p)$배 해서 기댓값을 유지하는 구현. 추론 때는 아무것도 하지 않는다. 지금 프레임워크의 표준이다.

**Early stopping (조기 종료)**: validation error가 가장 낮았던 시점의 파라미터를 최종 모델로 쓰는 것.
*Stopping training (or keeping the checkpoint) where validation error is lowest.*

**Data augmentation (데이터 증강)**: 답을 바꾸지 않는 변환(뒤집기, 자르기, 색 변화, noise)을 입력에 적용해서 학습 데이터를 늘리는 것.
*Training on label-preserving transformations of the inputs.*

**Ensemble (앙상블)**: 여러 모델의 예측을 평균하는 것. variance가 줄어든다.

### Inverted dropout의 기댓값과 분산

activation $h$에 mask $m \sim \text{Bernoulli}(1 - p)$ (1이면 남김)를 곱하고 $1/(1 - p)$로 키운다.

$$
\tilde{h} = \frac{m\,h}{1 - p}
$$

$\mathbb{E}[m] = \mathbb{E}[m^2] = 1 - p$이므로

$$
\mathbb{E}[\tilde{h}] = \frac{(1 - p)h}{1 - p} = h, \qquad
\mathbb{E}[\tilde{h}^2] = \frac{(1 - p)h^2}{(1 - p)^2} = \frac{h^2}{1 - p}
$$

$$
\text{Var}[\tilde{h}] = \frac{h^2}{1 - p} - h^2 = h^2\,\frac{p}{1 - p}
$$

기댓값이 그대로라서 추론 때는 dropout을 끄고 $h$를 그대로 쓰면 된다. (원 논문은 학습 때 키우지 않고 추론 때 $(1 - p)$를 곱했다. 결과는 같다.) backward에서는 forward에서 쓴 **같은 mask와 같은 배율**을 gradient에 곱한다. 10번 레슨(#자주-나오는-노드의-패턴)의 곱셈 노드 규칙 그대로다.

### Dropout ≈ 데이터에 맞춘 L2

입력 $\mathbf{x}$에 dropout을 건 linear regression $\hat{y} = \mathbf{w}^\top\tilde{\mathbf{x}}$, $\tilde{x}_j = m_j x_j/(1 - p)$를 보자. mask에 대한 기대 loss는, 기댓값과 분산으로 나누면 ($\mathbb{E}[(y - u)^2] = (y - \mathbb{E}u)^2 + \text{Var}\,u$)

$$
\mathbb{E}_m\left[(y - \mathbf{w}^\top\tilde{\mathbf{x}})^2\right]
= (y - \mathbf{w}^\top\mathbf{x})^2 + \sum_j w_j^2\,\text{Var}[\tilde{x}_j]
= (y - \mathbf{w}^\top\mathbf{x})^2 + \frac{p}{1 - p}\sum_j w_j^2 x_j^2
$$

($m_j$들이 독립이라 분산이 더해진다.) 즉 dropout은 평균적으로 **$w_j^2$에 그 feature의 크기 $x_j^2$를 곱한 L2 벌점**을 준다. 자주 크게 나오는 feature의 weight를 더 세게 누른다. 신경망에서도 국소적으로 비슷한 효과가 있다.

**앙상블 해석**: hidden $n$개에 dropout을 걸면 가능한 mask가 $2^n$개다. 학습은 weight를 공유하는 $2^n$개 sub-network를 번갈아 학습하는 것이고, 추론 때 dropout을 끄는 것은 그 앙상블의 (근사) 평균이다.

### Early stopping ≈ ridge

05번 레슨(#여러-차원-eigen-방향으로-쪼개기)처럼 2차식 loss를 eigen 방향으로 쪼개자. $S = \frac{1}{N}X^\top X$의 eigenvalue $s_i$, regularization 없는 최적해 $\hat{z}_i$, 0에서 시작하는 GD $\mathbf{w} \leftarrow \mathbf{w} - \eta(S\mathbf{w} - \frac{1}{N}X^\top\mathbf{y})$를 $t$ step 하면 오차가 매번 $(1 - \eta s_i)$배이므로

$$
z_i(t) = \left[1 - (1 - \eta s_i)^t\right]\hat{z}_i
$$

15번 레슨(#ridge의-해와-shrinkage)의 ridge는 $z_i = \frac{s_i}{s_i + \lambda}\hat{z}_i$였다. 두 배율을 비교하면

| | 곡률 큰 방향 ($s_i$ 큼) | 곡률 작은 방향 ($s_i$ 작음) |
|---|---|---|
| Early stopping | $\approx 1$ (이미 수렴) | $\approx \eta s_i t$ (거의 못 움직임) |
| Ridge | $\approx 1$ | $\approx s_i / \lambda$ |

작은 $s_i$에서 둘이 같아지려면 $\lambda \approx \dfrac{1}{\eta t}$. **학습 step 수가 regularization 강도의 역수 역할**을 한다. 오래 학습할수록 regularization이 약한 모델이다. 그래서 validation error가 U자를 그리고, 그 바닥에서 멈추는 것이 $\lambda$를 validation으로 고르는 것과 같은 일이 된다.

### 입력 noise ≈ L2

augmentation의 가장 단순한 형태인 Gaussian noise $\tilde{\mathbf{x}} = \mathbf{x} + \boldsymbol{\varepsilon}$, $\boldsymbol{\varepsilon} \sim \mathcal{N}(0, \sigma_\varepsilon^2 I)$를 linear regression에 쓰면, dropout과 같은 계산으로

$$
\mathbb{E}_\varepsilon\left[(y - \mathbf{w}^\top\tilde{\mathbf{x}})^2\right] = (y - \mathbf{w}^\top\mathbf{x})^2 + \sigma_\varepsilon^2\lVert\mathbf{w}\rVert^2
$$

정확히 ridge 벌점이다. 이미지 뒤집기나 자르기는 이렇게 깔끔한 식은 안 나오지만 같은 원리다. "입력이 이 정도 바뀌어도 출력이 바뀌지 않게" 만들어서 함수를 매끄럽게 한다.

## Worked example

### 예제 1. Dropout forward

$\mathbf{h} = (2, 0, 4, 1)$, $p = 0.5$, 이번 step의 mask가 $(1, 0, 0, 1)$이면

$$
\tilde{\mathbf{h}} = \frac{(1, 0, 0, 1) \odot (2, 0, 4, 1)}{0.5} = (4, 0, 0, 2)
$$

- 평균내면 원래 값: 각 원소가 확률 0.5로 $2h$, 0.5로 0이므로 기댓값 $h$
- 분산: $h^2 \cdot 0.5/0.5 = h^2$ → $(4, 0, 16, 1)$
- backward: upstream $(g_1, g_2, g_3, g_4)$에 같은 mask와 배율을 곱해 $(2g_1, 0, 0, 2g_4)$
- 추론: $\tilde{\mathbf{h}} = \mathbf{h} = (2, 0, 4, 1)$ 그대로

### 예제 2. Dropout 벌점 직접 계산

$\mathbf{x} = (1, 3)$, $\mathbf{w} = (2, -1)$, $y = 0.5$, $p = 0.5$. dropout 없는 예측 $\mathbf{w}^\top\mathbf{x} = 2 - 3 = -1$, 오차² $= 1.5^2 = 2.25$.

벌점 $= \frac{0.5}{0.5}(2^2 \cdot 1^2 + (-1)^2 \cdot 3^2) = 4 + 9 = 13$. 기대 loss $= 15.25$.

검산: mask 네 가지가 각각 확률 1/4이다. 둘 다 남김: 예측 $2 \cdot 2 - 6 = -2$, 오차² $6.25$. 첫째만: $4$, $12.25$. 둘째만: $-6$, $42.25$. 둘 다 끔: $0$, $0.25$. 평균 $(6.25 + 12.25 + 42.25 + 0.25)/4 = 15.25$. 맞다.

### 예제 3. Early stopping과 ridge 배율

$s = (1, 0.01)$, $\eta = 0.5$, $t = 20$.

- early stopping: $1 - 0.5^{20} \approx 1.000$, $1 - 0.995^{20} = 0.095$
- ridge $\lambda = 1/(\eta t) = 0.1$: $\frac{1}{1.1} = 0.909$, $\frac{0.01}{0.11} = 0.091$

곡률 작은 방향은 0.095와 0.091로 거의 같다. 곡률 큰 방향은 early stopping이 덜 줄인다(1.0 vs 0.909). 완전히 같지는 않지만 "noise 방향을 누른다"는 핵심 효과가 같다.

## 코드

```python
import numpy as np

rng = np.random.default_rng(0)

# 1) Inverted dropout: 기댓값은 그대로, 분산은 h^2 p/(1-p)
def dropout(h, p, rng):
    mask = rng.random(h.shape) >= p          # 확률 1-p로 남김
    return h * mask / (1 - p), mask

h = np.array([2.0, 0.0, 4.0, 1.0]); p = 0.5
samples = np.array([dropout(h, p, rng)[0] for _ in range(100_000)])
print("mean     :", samples.mean(0).round(3), " (h =", h, ")")
print("variance :", samples.var(0).round(3), " (theory", (h**2 * p / (1 - p)).round(3), ")")

# 2) 입력 dropout을 건 linear regression의 기대 loss = MSE + p/(1-p) * sum w_j^2 x_j^2
x = np.array([1.0, 3.0]); w = np.array([2.0, -1.0]); y = 0.5
sq = [(y - w @ dropout(x, p, rng)[0]) ** 2 for _ in range(200_000)]
print(f"E[loss] sim = {np.mean(sq):.3f}, theory = {(y - w @ x)**2 + p/(1-p) * np.sum(w**2 * x**2):.3f}")

# 3) Early stopping: feature가 많은 linear regression을 GD로 학습하며 val error 추적
N, D = 60, 40
w_true = rng.normal(0, 1, D) * (rng.random(D) < 0.3)
def make(n):
    X = rng.normal(size=(n, D)); return X, X @ w_true + rng.normal(0, 1.0, n)
X, y = make(N); X_val, y_val = make(200); X_te, y_te = make(5000)
mse = lambda w, A, b: np.mean((A @ w - b) ** 2)

w = np.zeros(D); lr = 0.01; hist = []
for t in range(1, 3001):
    w -= lr * (2 / N) * X.T @ (X @ w - y)
    hist.append((t, mse(w, X, y), mse(w, X_val, y_val), mse(w, X_te, y_te)))
best = min(hist, key=lambda r: r[2])
print(" step | train | val   | test")
for r in [hist[9], hist[49], best, hist[-1]]:
    tag = "  <- best val" if r is best else ""
    print(f" {r[0]:4d} | {r[1]:.3f} | {r[2]:.3f} | {r[3]:.3f}{tag}")

# early stopping step t에 대응하는 ridge: lambda ≈ 1/(lr * t)  (loss = (1/N)||Xw-y||^2 + lambda||w||^2 기준)
lam = 1 / (2 * lr * best[0])      # 이 loss의 gradient에 2가 있어서 실효 step이 2*lr
w_r = np.linalg.solve(X.T @ X / N + lam * np.eye(D), X.T @ y / N)
print(f"ridge lambda={lam:.4f}: train {mse(w_r, X, y):.3f} | val {mse(w_r, X_val, y_val):.3f} | test {mse(w_r, X_te, y_te):.3f}")
```

```text
mean     : [2.005 0.    3.977 1.   ]  (h = [2. 0. 4. 1.] )
variance : [ 4.     0.    15.999  1.   ]  (theory [ 4.  0. 16.  1.] )
E[loss] sim = 15.250, theory = 15.250
 step | train | val   | test
   10 | 8.069 | 10.688 | 11.469
   50 | 2.023 | 5.584 | 6.086
  308 | 0.221 | 2.438 | 2.429  <- best val
 3000 | 0.102 | 3.208 | 3.107
ridge lambda=0.1623: train 0.568 | val 2.768 | test 2.894
```

볼 포인트:
- dropout 기댓값과 분산이 유도한 식과 맞고, 예제 2의 15.25도 시뮬레이션과 맞는다.
- **Early stopping**: feature 40개에 데이터 60개라 끝까지(3000 step) 학습하면 train 0.10, val 3.21로 overfit된다. val이 가장 낮은 308 step에서 멈추면 test 2.43으로 더 좋다.
- 그 step에 대응하는 ridge($\lambda = 1/(2\eta t)$, 이 loss는 gradient에 2가 붙어 실효 learning rate가 $2\eta$)도 test 2.89로 끝까지 학습한 것보다 좋다. 둘이 정확히 같지는 않은 것은 예제 3에서 본 곡률 큰 방향의 차이 때문이다.

## 흔한 오해

<Aside type="caution" title="추론 때도 dropout을 켜 둬야 학습 때와 같은 분포가 된다?">
inverted dropout은 학습 때 이미 $1/(1-p)$로 키워서 기댓값을 맞춰 뒀으므로 추론 때는 끄고 그대로 쓴다. PyTorch의 `model.eval()`이 dropout을 끈다. 켜 두면 예측이 매번 달라진다(불확실성 추정용으로 일부러 켜는 MC dropout은 예외).
</Aside>

<Aside type="caution" title="Early stopping은 학습을 덜 한 것이라 regularization과는 다른 얘기다?">
위 유도대로 2차식에서는 $\lambda \approx 1/(\eta t)$인 ridge와 거의 같다. step 수가 hyperparameter인 regularization이다. 그래서 early stopping으로 고른 step을 기억해 두었다가, 데이터를 합쳐 다시 학습할 때 같은 step 수를 쓴다.
</Aside>

<Aside type="caution" title="Augmentation은 아무 변환이나 많이 넣을수록 좋다?">
답을 바꾸는 변환은 오히려 해롭다. 숫자 6을 180도 돌리면 9가 되고, 좌우가 의미 있는 데이터(글자, 의료 영상의 좌우)를 뒤집으면 틀린 label을 가르친다. 변환은 "이 변화에 답이 안 바뀐다"는 사전 지식이 맞을 때만 쓴다.
</Aside>

## Efficient ML 연결

**LLM pretraining은 dropout을 거의 안 쓴다.** 데이터가 수조 token이고 보통 한 번(1 epoch)만 보므로 같은 샘플을 외울 기회가 적다. variance보다 bias(모델 크기)가 문제라서 dropout을 0으로 둔다. 반대로 데이터가 적은 fine-tuning에서는 쓴다. LoRA에도 `lora_dropout` 옵션이 있다.

**Dropout은 구조적 pruning을 위한 학습이 될 수 있다.** LayerDrop(Fan et al., 2019)은 학습 중 Transformer layer를 통째로 무작위로 건너뛴다. 그렇게 학습된 모델은 추론 때 layer 일부를 빼도 성능이 덜 떨어져서, 재학습 없이 깊이를 줄일 수 있다. 무작위로 끄는 것에 익숙해진 모델이 일부를 영구히 끄는 것(pruning)에도 강하다.

**Distillation과 augmentation.** knowledge distillation은 teacher의 soft label(04번 레슨(#worked-example)의 temperature)을 써서 작은 student를 학습한다. hard label보다 정보가 많아 regularization 효과가 있고, augmentation한 입력에도 teacher가 label을 줄 수 있어서 둘이 같이 쓰인다. 데이터가 적은 on-device 학습에서 augmentation은 가장 싼 regularization이다.

## 서술형

### 문제. 입력 noise와 ridge

linear regression $\hat{y} = \mathbf{w}^\top\mathbf{x}$를 학습할 때 매 step 입력에 $\boldsymbol{\varepsilon} \sim \mathcal{N}(0, \sigma_\varepsilon^2 I)$를 더한다(augmentation).

(a) $\mathbb{E}_\varepsilon\left[(y - \mathbf{w}^\top(\mathbf{x} + \boldsymbol{\varepsilon}))^2\right] = (y - \mathbf{w}^\top\mathbf{x})^2 + \sigma_\varepsilon^2\lVert\mathbf{w}\rVert^2$을 유도하라.

(b) 전체 loss가 $\frac{1}{N}\sum_i(\cdot)^2$일 때, 이것은 15번 레슨의 어떤 regularization과 같고 그 강도는? $\mathbf{w} = (1, -2)$, $\sigma_\varepsilon = 0.1$이면 벌점은 얼마인가?

(c) 같은 모델에 입력 dropout($p$)을 쓰면 벌점이 $\frac{p}{1 - p}\sum_j w_j^2 x_j^2$였다. feature 하나의 단위를 m에서 mm로 바꿔 값이 1000배가 되면(그에 맞춰 최적 weight는 1/1000배), 두 방법의 벌점은 각각 어떻게 바뀌나? 어느 쪽이 feature 단위에 영향을 받지 않나?

<details>
<summary>풀이 보기</summary>

**(a)** $u = \mathbf{w}^\top(\mathbf{x} + \boldsymbol{\varepsilon}) = \mathbf{w}^\top\mathbf{x} + \mathbf{w}^\top\boldsymbol{\varepsilon}$. $\mathbb{E}[u] = \mathbf{w}^\top\mathbf{x}$, $\text{Var}[u] = \text{Var}\left[\sum_j w_j\varepsilon_j\right] = \sum_j w_j^2\sigma_\varepsilon^2 = \sigma_\varepsilon^2\lVert\mathbf{w}\rVert^2$ ($\varepsilon_j$ 독립). $\mathbb{E}[(y - u)^2] = (y - \mathbb{E}u)^2 + \text{Var}\,u$이므로 식이 나온다.

**(b)** 샘플마다 같은 벌점이 붙으므로 평균을 내도 $\frac{1}{N}\sum_i (y_i - \mathbf{w}^\top\mathbf{x}_i)^2 + \sigma_\varepsilon^2\lVert\mathbf{w}\rVert^2$. L2(ridge)이고 $\lambda\lVert\mathbf{w}\rVert^2$ 꼴로 쓰면 $\lambda = \sigma_\varepsilon^2$. 숫자: $0.01 \times (1 + 4) = 0.05$.

**(c)** 해당 feature의 값이 $1000x_j$, weight가 $w_j/1000$이 된다.

- 입력 noise(ridge): 벌점 $\sigma_\varepsilon^2 w_j^2$가 $\sigma_\varepsilon^2 w_j^2 / 10^6$이 된다. 같은 크기의 noise($\sigma_\varepsilon$)가 큰 단위의 feature에는 상대적으로 무시할 만큼 작아져서 그 feature를 거의 regularize하지 않는다. **단위에 영향을 받는다.** (그래서 ridge 전에 feature를 standardize한다.)
- dropout: $w_j^2 x_j^2$가 $(w_j/1000)^2(1000x_j)^2 = w_j^2 x_j^2$로 **그대로**다. dropout은 값을 비율로 끄는 것이라 단위와 무관하다.

</details>
