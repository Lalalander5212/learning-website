## 왜 필요한가

10번 레슨에서는 스칼라 노드 하나하나에 chain rule을 적용했다. 그런데 784 → 256 층 하나에 weight가 20만 개다. weight마다 노드를 만들면 느리고, GPU가 잘하는 것은 스칼라 연산이 아니라 **행렬곱(GEMM)** 이다. 이 레슨에서는 층 하나 단위로 backward를 행렬식으로 유도한다. 결론은 forward 행렬곱 1개마다 backward 행렬곱 2개이고, 이 식만 알면 어떤 깊이의 MLP든 backward를 쓸 수 있다. 12번 레슨에서 이 식을 그대로 구현해 MLP를 학습시킨다.

## 직관: shape가 답을 알려준다

```text
forward:   X (B×in)  ──[ · Wᵀ (in×out) ]──►  Z (B×out)

backward:  dX (B×in) ◄──[ · W (out×in) ]──  G = dL/dZ (B×out)
           dW (out×in) = Gᵀ (out×B) · X (B×in)
           db (out)    = G를 batch 방향으로 합
```

gradient는 원래 변수와 **shape가 같아야** 한다($\partial L/\partial W$는 $W$와 같은 out×in). 가진 재료가 $G$ (B×out), $X$ (B×in), $W$ (out×in)뿐이라서, shape가 맞게 곱하는 방법이 사실상 하나뿐이다. 유도를 잊어도 shape로 다시 맞출 수 있다. 그래도 아래에서 인덱스로 정확히 유도한다.

## 정식 설명

### 용어

**Jacobian (야코비안)**: 벡터 함수의 출력 각 성분을 입력 각 성분으로 미분한 행렬. backprop은 Jacobian을 **명시적으로 만들지 않고** upstream 벡터와의 곱만 계산한다(vector-Jacobian product, VJP).
*The matrix of all first-order partial derivatives of a vector-valued function.*

**Error signal (오차 신호)** $\delta^{(\ell)}$ 또는 $G^{(\ell)}$: $\partial L / \partial Z^{(\ell)}$, 층 $\ell$의 pre-activation에 대한 gradient. backprop은 이 값을 층마다 뒤로 넘긴다.
*The gradient of the loss with respect to a layer's pre-activations.*

**Elementwise product (원소별 곱, Hadamard product)** $\odot$: 같은 shape 행렬의 같은 위치끼리 곱.

### Linear layer의 backward

batch 형태 (09번 레슨(#forward-pass)): $Z = XW^\top + \mathbf{1}\mathbf{b}^\top$, $X \in \mathbb{R}^{B \times n}$, $W \in \mathbb{R}^{m \times n}$, $Z \in \mathbb{R}^{B \times m}$. 원소로 쓰면

$$
Z_{ij} = \sum_{k=1}^{n} X_{ik} W_{jk} + b_j
$$

upstream $G = \partial L / \partial Z$ ($B \times m$)를 받았다고 하자. $L$은 모든 $Z_{ij}$를 통해 $W$에 의존하므로 (10번 레슨(#경로가-여러-개면-더한다)의 "경로가 여러 개면 더한다")

**$W$에 대해**: $\partial Z_{ij} / \partial W_{jk} = X_{ik}$이고, $W_{jk}$는 $j$번째 열의 $Z_{ij}$들($i = 1..B$)에만 영향을 준다.

$$
\frac{\partial L}{\partial W_{jk}} = \sum_{i=1}^{B} G_{ij} X_{ik} = (G^\top X)_{jk}
\quad\Rightarrow\quad
\boxed{\frac{\partial L}{\partial W} = G^\top X}
$$

**$\mathbf{b}$에 대해**: $\partial Z_{ij} / \partial b_j = 1$

$$
\frac{\partial L}{\partial b_j} = \sum_{i=1}^{B} G_{ij}
\quad\Rightarrow\quad
\boxed{\frac{\partial L}{\partial \mathbf{b}} = G^\top \mathbf{1}} \;(\text{batch 방향 합})
$$

**$X$에 대해**: $\partial Z_{ij} / \partial X_{ik} = W_{jk}$이고, $X_{ik}$는 $i$번째 행의 $Z_{ij}$들($j = 1..m$)에 영향을 준다.

$$
\frac{\partial L}{\partial X_{ik}} = \sum_{j=1}^{m} G_{ij} W_{jk} = (GW)_{ik}
\quad\Rightarrow\quad
\boxed{\frac{\partial L}{\partial X} = G W}
$$

$\partial L / \partial X$는 앞 층의 upstream이 된다. 10번 레슨(#자주-나오는-노드의-패턴)의 곱셈 노드 규칙("상대편 값을 곱한다")이 행렬 버전으로 나온 것이다. $\partial W$에는 $X$를, $\partial X$에는 $W$를 곱한다.

샘플 하나($B = 1$, 열벡터 표기)로 쓰면 $\partial L/\partial W = \boldsymbol{\delta}\,\mathbf{x}^\top$ (outer product), $\partial L / \partial \mathbf{x} = W^\top \boldsymbol{\delta}$다.

### Activation의 backward

$H = \phi(Z)$는 원소별이므로 Jacobian이 대각이고, VJP는 원소별 곱이 된다.

$$
\frac{\partial L}{\partial Z} = \frac{\partial L}{\partial H} \odot \phi'(Z)
$$

ReLU면 $\phi'(Z) = \mathbb{1}[Z > 0]$이라 **mask**다. upstream 중 $Z > 0$인 위치만 통과시킨다.

### Softmax + cross-entropy의 backward

04번 레슨(#gradient-유도)에서 샘플 하나의 logit gradient가 $\mathbf{p} - \mathbf{y}$였다. batch 평균 loss $L = \frac{1}{B}\sum_i \ell_i$이면

$$
G^{(\text{out})} = \frac{\partial L}{\partial Z^{(\text{out})}} = \frac{1}{B}(P - Y)
$$

$Y$는 one-hot 행렬. $\frac{1}{B}$를 빼먹으면 gradient가 batch size배 커진다.

### 2층 MLP 전체

forward: $Z_1 = XW_1^\top + \mathbf{b}_1$, $H = \text{ReLU}(Z_1)$, $Z_2 = HW_2^\top + \mathbf{b}_2$, $P = \text{softmax}(Z_2)$

backward:

$$
\begin{aligned}
G_2 &= (P - Y)/B \\
\partial W_2 &= G_2^\top H, \quad \partial \mathbf{b}_2 = G_2^\top \mathbf{1} \\
\partial H &= G_2 W_2 \\
G_1 &= \partial H \odot \mathbb{1}[Z_1 > 0] \\
\partial W_1 &= G_1^\top X, \quad \partial \mathbf{b}_1 = G_1^\top \mathbf{1}
\end{aligned}
$$

층이 $L$개면 같은 두 줄(linear backward, activation backward)을 반복한다.

$$
G_\ell = \left(G_{\ell+1} W_{\ell+1}\right) \odot \phi'(Z_\ell)
$$

이 재귀식이 backpropagation의 전부다. **저장해야 하는 것**: 각 층의 입력($X$, $H$)과 activation mask($Z_1 > 0$), 그리고 $P$.

### FLOPs: 6 × 파라미터

linear layer 하나($n \to m$, batch $B$)에서

| 계산 | 행렬곱 | FLOPs |
|---|---|---|
| forward $XW^\top$ | $(B \times n)(n \times m)$ | $2Bnm$ |
| backward $\partial W = G^\top X$ | $(m \times B)(B \times n)$ | $2Bnm$ |
| backward $\partial X = GW$ | $(B \times m)(m \times n)$ | $2Bnm$ |

합 $6Bnm = 6 \times B \times (\text{파라미터 수})$. 학습 FLOPs가 "token당 $6N$"(N = 파라미터 수)이라는 LLM 어림이 여기서 나온다.

## Worked example

$d = 2$, hidden $h = 2$, class $k = 2$, 샘플 1개.

$$
\mathbf{x} = (1, 2),\;
W_1 = \begin{bmatrix} 1 & -1 \\ 0.5 & 0.5 \end{bmatrix},\;
W_2 = \begin{bmatrix} 1 & 2 \\ -1 & 1 \end{bmatrix},\;
\mathbf{b}_1 = \mathbf{b}_2 = 0,\; \text{정답 class 2} \;(\mathbf{y} = (0, 1))
$$

**Forward**

1. $\mathbf{z}_1 = W_1 \mathbf{x} = (1 - 2,\; 0.5 + 1) = (-1, 1.5)$
2. $\mathbf{h} = \text{ReLU}(\mathbf{z}_1) = (0, 1.5)$
3. $\mathbf{z}_2 = W_2 \mathbf{h} = (0 + 3,\; 0 + 1.5) = (3, 1.5)$
4. $\mathbf{p} = \text{softmax}(3, 1.5)$: $e^3 = 20.09$, $e^{1.5} = 4.48$, 합 24.57 → $\mathbf{p} = (0.8176, 0.1824)$
5. $L = -\ln 0.1824 = 1.7014$

**Backward**

1. $\boldsymbol{\delta}_2 = \mathbf{p} - \mathbf{y} = (0.8176, -0.8176)$
2. $\partial W_2 = \boldsymbol{\delta}_2 \mathbf{h}^\top = \begin{bmatrix} 0.8176 \\ -0.8176 \end{bmatrix}\begin{bmatrix} 0 & 1.5 \end{bmatrix} = \begin{bmatrix} 0 & 1.2264 \\ 0 & -1.2264 \end{bmatrix}$, $\partial \mathbf{b}_2 = \boldsymbol{\delta}_2$
3. $\partial \mathbf{h} = W_2^\top \boldsymbol{\delta}_2 = (1 \times 0.8176 + (-1)(-0.8176),\; 2 \times 0.8176 + 1 \times (-0.8176)) = (1.6351, 0.8176)$
4. ReLU mask $\mathbb{1}[\mathbf{z}_1 > 0] = (0, 1)$ → $\boldsymbol{\delta}_1 = (0, 0.8176)$
5. $\partial W_1 = \boldsymbol{\delta}_1 \mathbf{x}^\top = \begin{bmatrix} 0 & 0 \\ 0.8176 & 1.6351 \end{bmatrix}$, $\partial \mathbf{b}_1 = (0, 0.8176)$

읽는 법:
- $\partial W_2$의 첫 열이 0이다. $h_1 = 0$이라 그 hidden에서 나가는 weight는 loss에 영향이 없다.
- $\partial W_1$의 첫 행이 0이다. 첫 hidden neuron이 ReLU에서 꺼져서($z = -1$) gradient가 끊겼다. 이 샘플에서 그 neuron은 학습되지 않는다.
- $\boldsymbol{\delta}_2$에서 정답 class 쪽 logit은 올라가고(gradient 음수), 오답 class는 내려간다.

## 코드

```python
import numpy as np

def softmax(Z):
    Z = Z - Z.max(axis=1, keepdims=True)        # log-sum-exp 안정화 (04번 레슨)
    E = np.exp(Z)
    return E / E.sum(axis=1, keepdims=True)

def forward_backward(X, Y, W1, b1, W2, b2):
    """X: (B, d), Y: one-hot (B, k). 반환: loss, grads dict"""
    B = X.shape[0]
    # forward (backward에 쓸 값 저장)
    Z1 = X @ W1.T + b1          # (B, h)
    H = np.maximum(Z1, 0)       # (B, h)
    Z2 = H @ W2.T + b2          # (B, k)
    P = softmax(Z2)
    loss = -np.sum(Y * np.log(P)) / B

    # backward
    G2 = (P - Y) / B            # dL/dZ2   (B, k)
    dW2 = G2.T @ H              # (k, h)
    db2 = G2.sum(axis=0)        # (k,)
    dH = G2 @ W2                # (B, h)
    G1 = dH * (Z1 > 0)          # ReLU mask, dL/dZ1 (B, h)
    dW1 = G1.T @ X              # (h, d)
    db1 = G1.sum(axis=0)        # (h,)
    return loss, dict(W1=dW1, b1=db1, W2=dW2, b2=db2), dict(Z1=Z1, H=H, Z2=Z2, P=P)

# worked example
X = np.array([[1.0, 2.0]])
Y = np.array([[0.0, 1.0]])                  # 정답: 두 번째 class
W1 = np.array([[1.0, -1.0], [0.5, 0.5]]); b1 = np.zeros(2)
W2 = np.array([[1.0, 2.0], [-1.0, 1.0]]); b2 = np.zeros(2)

loss, g, cache = forward_backward(X, Y, W1, b1, W2, b2)
np.set_printoptions(precision=4, suppress=True)
print("Z1", cache["Z1"], " H", cache["H"], " Z2", cache["Z2"], " P", cache["P"])
print(f"loss = {loss:.4f}")
for k in ["W2", "b2", "W1", "b1"]:
    print(f"d{k} =\n{g[k]}")

# batch에서도 shape가 맞는지 확인
rng = np.random.default_rng(0)
Xb = rng.normal(size=(32, 2)); Yb = np.eye(2)[rng.integers(0, 2, 32)]
_, gb, _ = forward_backward(Xb, Yb, W1, b1, W2, b2)
print({k: v.shape for k, v in gb.items()})
```

볼 포인트:
- backward 부분이 위의 수식 다섯 줄과 한 줄씩 대응한다. `G2.T @ H`, `G2 @ W2`, `dH * (Z1 > 0)`.
- batch 32에서도 gradient shape가 파라미터 shape와 같다. 이 확인(assert)이 구현 버그를 가장 빨리 잡는다.
- 이 식이 맞는지 숫자로 검증하는 방법(gradient check)은 12번 레슨(#gradient-check-절차)에서 한다.

## 흔한 오해

<Aside type="caution" title="dW = X^T G 아닌가?">
weight를 (out, in)으로 두면 $\partial W = G^\top X$ (out × in)이고, (in, out)으로 두고 $Z = XW$로 쓰면 $\partial W = X^\top G$ (in × out)다. 둘 다 맞고 convention 차이다. 교재와 코드의 shape convention을 먼저 확인하고, 헷갈리면 shape를 맞춰 본다.
</Aside>

<Aside type="caution" title="Bias gradient도 batch 평균을 내야 한다?">
$\frac{1}{B}$는 이미 $G_2 = (P - Y)/B$에 들어 있다. 그 뒤로는 $\partial \mathbf{b} = G^\top \mathbf{1}$로 **합**만 한다. 여기서 또 평균을 내면 bias gradient만 $1/B$배 작아진다.
</Aside>

<Aside type="caution" title="Backward에서 softmax의 Jacobian을 만들어 곱해야 한다?">
softmax의 Jacobian은 $k \times k$ (vocab 5만이면 25억 원소)라 만들면 안 된다. cross-entropy와 합치면 $P - Y$로 약분되므로 그걸 바로 쓴다. 일반적으로도 backprop은 Jacobian을 만들지 않고 VJP만 계산한다.
</Aside>

## Efficient ML 연결

**학습 FLOPs = 3 × forward.** forward 행렬곱 1개에 backward 2개. 그래서 1B 파라미터 모델을 1조 token 학습하면 약 $6 \times 10^{9} \times 10^{12} = 6 \times 10^{21}$ FLOPs다. 학습 비용 어림, GPU 시간 계산의 기본식이다.

**Frozen weight는 dW를 건너뛴다.** LoRA나 TinyTL처럼 weight를 얼리면 그 층의 $\partial W = G^\top X$를 계산하지 않아도 된다. 그런데 앞쪽에 학습할 층이 있으면 $\partial X = GW$는 여전히 계산해야 upstream이 전달된다. 그래서 frozen 층의 backward는 FLOPs가 절반이 된다. 게다가 $\partial X = GW$에는 $X$가 필요 없으므로 **frozen 층의 입력 activation은 저장하지 않아도 된다**(activation 함수의 mask는 필요).

**Activation 메모리.** 층마다 입력 $X$ ($B \times n$)를 backward까지 들고 있어야 한다. batch와 sequence 길이가 크면 weight보다 activation 메모리가 크다. quantized training이나 activation compression(저장할 때만 activation을 4~8 bit로 줄이기)이 이 부분을 노린다.

## 서술형

### 문제. Linear layer 하나의 backward 비용과 메모리

nn.Linear(1024, 4096), batch $B = 64$, FP16.

(a) $\partial L / \partial X = GW$를 인덱스 계산으로 유도하라. 이 계산에 forward 때의 $X$가 필요한가?

(b) forward, $\partial W$, $\partial X$ 각각의 FLOPs를 구하라.

(c) 이 층의 weight를 얼리고(LoRA처럼) 앞쪽 층만 학습한다면 backward FLOPs는 얼마가 되나? 이 층이 네트워크의 **첫 층**이라면?

(d) weight를 학습할 때 backward를 위해 저장해야 하는 입력 activation 크기는? weight를 얼리면 어떻게 되나?

<details>
<summary>풀이 보기</summary>

**(a)** $Z_{ij} = \sum_k X_{ik}W_{jk} + b_j$. $X_{ik}$는 같은 행 $i$의 모든 출력 $Z_{i1}, \dots, Z_{im}$에 $W_{jk}$의 비율로 들어간다. chain rule로 경로를 더하면

$$
\frac{\partial L}{\partial X_{ik}} = \sum_{j} \frac{\partial L}{\partial Z_{ij}} \frac{\partial Z_{ij}}{\partial X_{ik}} = \sum_j G_{ij} W_{jk} = (GW)_{ik}
$$

$G$와 $W$만 쓰므로 **$X$는 필요 없다.**

**(b)** $2Bnm = 2 \times 64 \times 1024 \times 4096 = 536.9$M FLOPs. forward, $\partial W$, $\partial X$ 모두 같은 크기라 backward 합은 1.07 GFLOPs, 전체 1.61 GFLOPs.

**(c)** $\partial W$를 건너뛰고 $\partial X$만 계산하므로 backward 536.9M FLOPs (절반). 첫 층이면 $\partial X$(입력 데이터에 대한 gradient)도 필요 없으므로 backward가 **0**이다.

**(d)** $\partial W = G^\top X$에 $X$가 필요하다. $64 \times 1024 \times 2 \text{ B} = 128$ KiB. weight를 얼리면 (a)에서 본 대로 $\partial X$에 $X$가 필요 없으므로 저장할 필요가 없다. 단 LoRA는 frozen $W$ 옆에 작은 $A, B$를 학습하고, $\partial A$ 계산에 $X$가 필요하므로 결국 $X$를 저장한다. 메모리를 줄이는 것은 weight gradient와 optimizer state 쪽이다.
